# SOC Home Lab

## Overview

A hands-on Security Operations Center (SOC) home lab designed to practice cybersecurity monitoring, log analysis, threat detection, and incident investigation.

## Objectives

- Understand basic SOC operations
- Analyze security logs
- Identify suspicious activity
- Investigate security events
- Practice incident-response techniques
- Document security findings professionally

## Lab Environment

- Operating System: Linux
- Security Tools: Wireshark, Nmap, and other security tools
- Virtualization: Virtual Machines
- Network: Isolated home lab environment

## Skills Demonstrated

- Log Analysis
- Network Analysis
- Threat Detection
- Incident Investigation
- Network Scanning
- Linux
- Cybersecurity Fundamentals
